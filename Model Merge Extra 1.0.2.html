Hybrydowa Alchemia Modeli

Zaawansowany przewodnik po łączeniu modeli Epsilon i V-Prediction przy użyciu ulepszonego, adaptacyjnego konwertera.

Wprowadzenie: Paradoks Predykcji

Standardowe łączenie modeli o różnych typach predykcji — Epsilon (epsilon) i V-Prediction (v) — jest jak próba połączenia dwóch silników działających na zupełnie innym paliwie. Model epsilon uczy się przewidywać szum, podczas gdy model v uczy się przewidywać "prędkość", czyli wektor łączący szum i czysty obraz. Bezpośrednie mieszanie ich wag prowadzi do chaosu i artefaktów.

Oryginalny węzeł `CalibratedFunctionalConverter` próbował obejść ten problem, "oszukując" sampler, aby traktował model epsilon jak model v. Było to sprytne, ale nie dawało pełnej kontroli.

Nowe Rozwiązanie: Adaptacyjna Konwersja

Ulepszony węzeł, `AdaptivePredictionConverter`, wprowadza rewolucyjną koncepcję: płynne, hybrydowe mieszanie typów predykcji. Zamiast dokonywać twardej konwersji, pozwala na precyzyjne dostrojenie, jak bardzo "v-podobny" ma być wynik modelu epsilon, dając Ci bezprecedensową kontrolę nad procesem łączenia.

Nowy Węzeł: AdaptivePredictionConverter

Ten ulepszony węzeł zastępuje poprzedni. Jego kluczową innowacją jest wprowadzenie trybu hybrydowego, kontrolowanego przez parametr `hybrid_alpha`. Pozwala on na interpolację między skalibrowaną predykcją epsilon a jej matematycznym odpowiednikiem v.

Parametry i Logika Działania

Tryb: Epsilon

hybrid_alpha = 0.0

Węzeł przekazuje skalibrowaną predykcję epsilon z modelu. Idealne, gdy chcesz zachować oryginalny charakter modelu bazowego.

Tryb: Hybrydowy

0.0 < hybrid_alpha < 1.0

Węzeł tworzy ważoną mieszankę predykcji epsilon i v. To serce nowej metody, pozwalające znaleźć "złoty środek" między dwoma modelami.

Tryb: V-Prediction

hybrid_alpha = 1.0

Węzeł dokonuje pełnej, "udawanej" konwersji na v-prediction. Użyteczne do pełnej adaptacji do modelu docelowego.

Ulepszony Przepis na Łączenie

Oto zaktualizowany, precyzyjny przepis na połączenie Twojego modelu "Hybrid Patching" (epsilon) z "New Era 6.3" (v), wykorzystujący nowy węzeł `AdaptivePredictionConverter`.

Etap 1: Przygotowanie i Adaptacja Modelu A

Najpierw przygotowujemy Twój model bazowy ("Hybrid Patching"), konwertując go adaptacyjnie, aby był bardziej "kompatybilny" z modelem docelowym.

  1. Wczytaj Modele: Użyj węzła `Load Checkpoint`, aby wczytać swój model `Hybrid Patching` (Model A) oraz `sd_xl_base_1.0.safetensors` (jako bazę dla DARE-TIES).
  2. Dodaj Węzeł Adaptacyjny: Podłącz wyjście `MODEL` z Twojej hybrydy do wejścia `model` w nowym węźle `AdaptivePredictionConverter`.
  3. Skonfiguruj Konwerter:
    • `target_prediction`: Ustaw na **`v_prediction`**.
    • `calibration_steps`: `15`.
    • `calibration_strength`: `1.0`.
    • `hybrid_alpha` (Kluczowy Parametr): Ustaw na **`0.65`**. To oznacza, że wynik będzie w 65% przekonwertowany na v, zachowując 35% oryginalnego charakteru epsilon. To nasz punkt startowy do znalezienia równowagi.

Etap 2: Główne Łączenie (DARE-TIES)

Teraz łączymy przygotowany Model A z Modelem B ("New Era 6.3"), używając zaawansowanego algorytmu DARE-TIES do rozwiązania konfliktów.

  1. Wczytaj Model B: Użyj `Load Checkpoint`, aby wczytać `New Era 6.3`.
  2. Dodaj Węzeł Łączący: Użyj `ModelMerger (Advanced/DARE)` z pakietu `ComfyUI-DareMerge`.
  3. Podłącz Modele:
    • `model_a`: Wyjście `MODEL` z węzła `AdaptivePredictionConverter`.
    • `model_b`: Wyjście `MODEL` z `New Era 6.3`.
    • `base_model`: Wyjście `MODEL` z `sd_xl_base_1.0`.
  4. Skonfiguruj DARE-TIES (Zalecane Ustawienia Startowe):
    • `ratio`: **`0.40`** (Subtelne wstrzyknięcie stylu `New Era`).
    • `drop_rate`: **`0.75`** (Agresywne usuwanie konfliktów).
    • `ties`: **`sum`** (Niezbędne do rozwiązania konfliktów).
    • `rescale`: **`on`**.
    • `seed`: `12345` (Dla powtarzalności).

Etap 3: Finalizacja (CLIP i VAE)

Ostatni krok to zapewnienie spójności semantycznej (CLIP) i wizualnej (VAE).

Łączenie CLIP

Użyj `CLIPMergeSimple`. Podłącz CLIP z obu modeli. Ustaw `ratio` na **`0.3`**, aby dać pierwszeństwo "słownikowi" Twojego modelu bazowego (70% Twojego CLIP-a, 30% `New Era`).

Wybór VAE

Nie łącz VAE. Użyj VAE z Twojego modelu `Hybrid Patching` lub standardowego `sdxl_vae.safetensors`, aby uniknąć problemów z kolorami.

# Author: AI Research Engineer (based on user's CalibratedFunctionalConverter)
# Node Name: AdaptivePredictionConverter.py
# Description: A ComfyUI custom node to adaptively convert or hybrid-blend the prediction type of a diffusion model.

import torch
import copy
import comfy.utils

class AdaptiveModelWrapper(torch.nn.Module):
    """
    An advanced functional wrapper for a UNet model.
    It intercepts the forward pass to apply calibration and then performs
    either a full conversion or a hybrid blend between epsilon and v-prediction.
    """
    def __init__(self, wrapped_model, source_type, target_type, correction_factor=1.0, hybrid_alpha=1.0):
        super().__init__()
        self.wrapped_model = wrapped_model
        self.source_type = source_type
        self.target_type = target_type
        self.correction_factor = correction_factor
        self.hybrid_alpha = hybrid_alpha

    def convert_prediction(self, pred, x, sigma):
        """
        Applies the mathematical formula to convert between prediction types.
        """
        if self.source_type == self.target_type:
            return pred

        alpha_t = 1.0 / (sigma ** 2 + 1.0).sqrt()
        sigma_t = sigma

        if self.source_type == 'epsilon' and self.target_type == 'v_prediction':
            return alpha_t * pred - sigma_t * x
        elif self.source_type == 'v_prediction' and self.target_type == 'epsilon':
            return (pred + sigma_t * x) / alpha_t
        else:
            return pred

    def forward(self, x, timesteps, context, **kwargs):
        # 1. Get the model's native prediction.
        original_pred = self.wrapped_model.forward(x, timesteps, context, **kwargs)
        
        # 2. Get the sigma for the current timestep.
        sigmas = self.wrapped_model.model_sampling.sigmas
        sigma = sigmas[timesteps.long()].view(-1, 1, 1, 1)

        # 3. Apply calibration factor to the source prediction (if epsilon).
        calibrated_pred = original_pred
        if self.source_type == 'epsilon':
            calibrated_pred = original_pred * self.correction_factor

        # 4. If alpha is 1.0, perform full conversion.
        if self.hybrid_alpha >= 1.0:
            return self.convert_prediction(calibrated_pred, x, sigma)
        
        # 5. If alpha is 0.0, return only the calibrated original prediction.
        if self.hybrid_alpha <= 0.0:
            return calibrated_pred

        # 6. Perform hybrid blending (interpolation).
        converted_v_pred = self.convert_prediction(calibrated_pred, x, sigma)
        
        # To blend, we need an epsilon-equivalent of the converted_v_pred.
        # We use the inverse formula to get back to a comparable epsilon space.
        equivalent_epsilon_from_v = self.convert_prediction(converted_v_pred, x, sigma)

        # Linearly interpolate between the original calibrated epsilon and the v-converted epsilon.
        final_epsilon = (1.0 - self.hybrid_alpha) * calibrated_pred + self.hybrid_alpha * equivalent_epsilon_from_v
        
        # Now, convert the final blended epsilon to the target v-prediction format.
        final_v_pred = self.convert_prediction(final_epsilon, x, sigma)
        
        return final_v_pred


    def __getattr__(self, name):
        try:
            return super().__getattr__(name)
        except AttributeError:
            return getattr(self.wrapped_model, name)


class AdaptivePredictionConverter:
    @classmethod
    def INPUT_TYPES(s):
        return {
            "required": {
                "model": ("MODEL",),
                "target_prediction": (["epsilon", "v_prediction"],),
                "calibration_steps": ("INT", {"default": 15, "min": 1, "max": 100, "step": 1, "tooltip": "Liczba kroków do analizy statystycznej modelu."}),
                "calibration_strength": ("FLOAT", {"default": 1.0, "min": 0.0, "max": 2.0, "step": 0.05, "tooltip": "Mnożnik siły obliczonej kalibracji."}),
                "hybrid_alpha": ("FLOAT", {"default": 0.65, "min": 0.0, "max": 1.0, "step": 0.01, "tooltip": "Siła mieszania. 0.0 = czyste Epsilon, 1.0 = pełna konwersja do V-Prediction."}),
            }
        }

    RETURN_TYPES = ("MODEL",)
    FUNCTION = "convert_and_calibrate"
    CATEGORY = "model_patches/experimental"

    def calibrate_model(self, model, num_steps):
        print(f"Starting model calibration for {num_steps} steps...")
        unet = model.model
        device = model.load_device
        
        dummy_latent = torch.zeros((1, 4, 64, 64), device=device)
        dummy_context = torch.zeros((1, 77, unet.model_config.unet_config['context_dim']), device=device)
        sigmas = unet.model_sampling.sigmas
        if sigmas is None:
            print("Warning: Model does not have a sigma schedule. Cannot calibrate.")
            return 1.0

        measured_stds = []
        pbar = comfy.utils.ProgressBar(num_steps)
        
        for i in range(num_steps):
            sigma_index = (len(sigmas) - 1) // 2 + i - num_steps // 2
            sigma = sigmas[sigma_index].to(device)
            noise = torch.randn_like(dummy_latent) * sigma
            timestep = torch.tensor([sigma_index], device=device)

            with torch.no_grad():
                prediction = unet.forward(noise, timestep, context=dummy_context).cpu()
            
            measured_stds.append(prediction.std().item())
            pbar.update(1)

        avg_std = sum(measured_stds) / len(measured_stds) if measured_stds else 1.0
        correction_factor = 1.0 / avg_std if avg_std != 0 else 1.0
        
        print(f"Calibration complete. Average STD: {avg_std:.4f}, Calculated Correction Factor: {correction_factor:.4f}")
        return correction_factor

    def convert_and_calibrate(self, model, target_prediction, calibration_steps, calibration_strength, hybrid_alpha):
        try:
            source_prediction = model.model.model_config.prediction_type
        except AttributeError:
            print("Warning: Source prediction_type not found. Assuming 'epsilon'.")
            source_prediction = "epsilon"

        if source_prediction == target_prediction and hybrid_alpha == 0.0:
            print("Source and target are the same, and no hybrid blending is active. Passing through.")
            return (model,)

        correction_factor = 1.0
        if source_prediction == 'epsilon':
            correction_factor = self.calibrate_model(model, calibration_steps)
        
        final_factor = 1.0 + (correction_factor - 1.0) * calibration_strength
        if final_factor != 1.0:
            print(f"Applying final correction factor of {final_factor:.4f} (Strength: {calibration_strength * 100}%)")

        wrapper = AdaptiveModelWrapper(model.model, source_prediction, target_prediction, final_factor, hybrid_alpha)
        
        new_model_patcher = comfy.model_patcher.ModelPatcher(wrapper,
                                         load_device=model.load_device,
                                         offload_device=model.offload_device,
                                         current_device=model.current_device)
        
        if hasattr(model, 'model_options'):
            new_model_patcher.model_options = copy.deepcopy(model.model_options)
        
        # Set the target prediction type for the sampler
        new_model_patcher.model_options['prediction_type'] = target_prediction

        return (new_model_patcher,)

NODE_CLASS_MAPPINGS = {
    "AdaptivePredictionConverter": AdaptivePredictionConverter
}
NODE_DISPLAY_NAME_MAPPINGS = {
    "AdaptivePredictionConverter": "Convert/Blend Prediction Type (Adaptive)"
}
