Filozofia Narzędzie Przepis Finalizacja

Przewodnik Połączenia: Projekt 'Nowa Hybryda'

Ewolucja modelu "Hybrydowego Łatania" poprzez fuzję z architekturą V-Prediction modelu New Era 6.3 w celu osiągnięcia nowej estetyki Dark-Retro-Fantasy.

Filozofia Połączenia

Twój oryginalny model, stworzony strategią "Hybrydowego Łatania", jest zaawansowaną konstrukcją opartą na architekturze `epsilon-prediction`. Jego siłą jest unikalna mieszanka bazy Pony z precyzyjną "łatką" anatomiczną z modelu SDXL. Jest to fundament o ogromnym potencjale.

Model New Era 6.3 to z kolei model `v-prediction`, znany z wyjątkowo czystego stylu retro anime i doskonałej spójności. Jego architektura, choć inna, idealnie pasuje do celu artystycznego Twojego projektu.

Cel jest prosty: połączyć to, co najlepsze z obu światów. Aby to osiągnąć, musimy najpierw przekonwertować Twoją hybrydę z `epsilon` na `v-prediction`. To pozwoli na architektonicznie poprawne i stabilne połączenie. Nowo powstały model połączy siłę kompozycyjną Twojej hybrydy z estetycznym mistrzostwem New Era, tworząc ostateczną wersję modelu do generowania zasobów w stylu Dark-Retro-Fantasy.

Narzędzie: Zaawansowany Konwerter Modeli

AdvancedModelConverter.py (v6)

Poniżej znajduje się ulepszona wersja skryptu konwertującego. Została zoptymalizowana pod kątem zarządzania pamięcią VRAM (kluczowe przy 8GB) i dodano więcej komunikatów, abyś wiedział, co dzieje się na każdym etapie tego powolnego procesu. Zapisz ten kod jako plik `.py` w folderze `ComfyUI/custom_nodes`.


# Author: AI Research Engineer (Enhanced by Gemini)
# Node Name: AdvancedModelConverter.py (v6)
# Description: An advanced, universal, experimental ComfyUI node to perform a one-shot, training-free recalculation 
#              of a model's UNet state_dict between epsilon and v-prediction, while correctly handling CLIP and VAE.
#              This version includes memory management optimizations and enhanced logging.

import torch
import comfy.utils
import comfy.model_management
import copy
import gc

class AdvancedModelConverter:
    """
    This node performs a training-free, one-shot recalculation of a model's UNet weights
    to convert it between epsilon-prediction and v-prediction formats.
    It takes MODEL, CLIP, and VAE as separate inputs, converts ONLY the UNet,
    and passes the original CLIP and VAE through, ensuring maximum coherence.
    The process is experimental, slow, and heuristic-based.
    v6: Enhanced memory management with gc.collect() and del, plus more verbose logging for user feedback.
    """
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "model": ("MODEL",),
                "clip": ("CLIP",),
                "vae": ("VAE",),
                "conversion_direction": (["epsilon_to_v", "v_to_epsilon"], {"default": "epsilon_to_v"}),
                "model_architecture": (["auto", "sd15", "sdxl"], {
                    "default": "auto",
                    "tooltip": "Automatycznie wykryj architekturę lub wskaż ją ręcznie (SD1.5/SDXL)."
                }),
                "processing_device": (["auto", "CPU", "GPU"], {
                    "default": "auto",
                    "tooltip": "Wybierz urządzenie do obliczeń. CPU jest wolniejsze, ale zużywa znacznie mniej VRAM."
                }),
                "recalculation_steps": ("INT", {
                    "default": 12, "min": 1, "max": 100, "step": 1,
                    "tooltip": "Liczba kroków (różnych poziomów szumu sigma) użytych do uśrednienia rekalkulacji. Więcej = potencjalnie lepsza jakość, ale wolniej."
                }),
                "calibration_strength": ("FLOAT", {
                    "default": 1.0, "min": 0.0, "max": 2.0, "step": 0.05,
                    "tooltip": "Siła kalibracji (tylko dla Epsilon -> V). 1.0 to pełna korekta. Zmniejsz, jeśli wynik jest zbyt 'przepalony'."
                }),
                "recalculation_strength": ("FLOAT", {
                    "default": 1.0, "min": 0.0, "max": 1.0, "step": 0.01,
                    "tooltip": "Siła mieszania nowych wag z oryginalnymi. 1.0 to pełna konwersja. Mniejsze wartości zachowują więcej z oryginału."
                }),
                "simulation_batch_size": ("INT", {
                    "default": 4, "min": 1, "max": 32, "step": 1,
                     "tooltip": "Rozmiar wsadu dla symulacji. Większy może być szybszy, ale zużywa więcej VRAM."
                }),
                "optimizer_lr": ("FLOAT", {
                    "default": 0.01, "min": 0.0001, "max": 0.1, "step": 0.0001,
                    "tooltip": "Współczynnik uczenia dla optymalizatora warstw konwolucyjnych. Zazwyczaj nie wymaga zmiany."
                }),
                "use_fp16": ("BOOLEAN", {
                    "default": True,
                    "tooltip": "Użyj precyzji fp16 na GPU. Wyłączenie może nieznacznie poprawić jakość kosztem VRAM i prędkości."
                }),
            }
        }

    RETURN_TYPES = ("MODEL", "CLIP", "VAE",)
    FUNCTION = "convert_model_holistic"
    CATEGORY = "model_patches/experimental"

    def _detect_model_arch(self, unet):
        print("Analizowanie architektury UNet...")
        arch_details = {'type': 'unknown', 'context_dim': 768, 'num_classes': None}
        if hasattr(unet, 'num_classes') and unet.num_classes is not None:
            arch_details['num_classes'] = unet.num_classes
        
        for name, param in unet.named_parameters():
            if "time_embed.2.weight" in name and param.shape[0] == 1280:
                arch_details.update({'type': 'sdxl', 'context_dim': 2048})
                if arch_details['num_classes'] is None:
                   arch_details['num_classes'] = 2816
                break
            if "input_blocks.0.0.weight" in name and hasattr(unet, 'in_channels') and unet.in_channels == 4:
                arch_details.update({'type': 'sd15', 'context_dim': 768})
                break
        
        print(f"--> Wykryta architektura: {arch_details['type'].upper()}, context_dim: {arch_details['context_dim']}, num_classes: {arch_details['num_classes']}")
        return arch_details

    def get_target_v_pred(self, epsilon_pred, x_t, sigma):
        alpha_t = torch.rsqrt(sigma.pow(2) + 1.0)
        return alpha_t * epsilon_pred - sigma * x_t

    def get_target_epsilon_pred(self, v_pred, x_t, sigma):
        alpha_t = torch.rsqrt(sigma.pow(2) + 1.0)
        if alpha_t.dtype == torch.float16:
            alpha_t = torch.max(alpha_t, torch.tensor(0.001, dtype=torch.float16, device=alpha_t.device))
        return (v_pred + sigma * x_t) / alpha_t

    def calibrate_model(self, model, unet, num_steps, device, dtype, arch_details):
        print(f"Rozpoczynanie kalibracji modelu ({num_steps} kroków)...")
        try:
            sigmas = model.model.model_sampling.sigmas
            if sigmas is None: raise AttributeError
        except AttributeError:
            print("--> Ostrzeżenie: Nie można znaleźć harmonogramu sigma. Kalibracja niemożliwa, zwracam współczynnik 1.0.")
            return 1.0

        context_dim = arch_details['context_dim']
        dummy_latent = torch.zeros((1, 4, 64, 64), device=device, dtype=dtype)
        dummy_context = torch.zeros((1, 77, context_dim), device=device, dtype=dtype)
        
        unet_kwargs = {"context": dummy_context}
        if arch_details['num_classes'] is not None:
            print(f"--> Wykryto model warunkowany klasą ({arch_details['num_classes']} klas).")
            try:
                num_classes = int(arch_details['num_classes'])
                dummy_y = torch.zeros(1, num_classes, device=device, dtype=dtype)
                dummy_y[0, 0] = 1.0
                unet_kwargs['y'] = dummy_y
            except (ValueError, TypeError):
                print(f"--> Błąd: Nie można przekonwertować num_classes na int. Kalibracja może się nie udać.")
                return 1.0
        
        measured_stds = []
        pbar_calib = comfy.utils.ProgressBar(num_steps)
        
        for i in range(num_steps):
            sigma_idx = max(0, min(len(sigmas) - 1, len(sigmas) // 2 + i - num_steps // 2))
            sigma = sigmas[sigma_idx].to(device, dtype=dtype)
            noise = torch.randn_like(dummy_latent) * sigma
            timestep = torch.tensor([sigma.item()], device=device, dtype=dtype)

            with torch.no_grad():
                prediction = unet(noise, timestep, **unet_kwargs).cpu()
            
            measured_stds.append(prediction.std().item())
            pbar_calib.update(1)

        avg_std = sum(measured_stds) / len(measured_stds) if measured_stds else 1.0
        correction_factor = 1.0 / avg_std if avg_std != 0 else 1.0
        
        print(f"--> Kalibracja zakończona. Średnie odchylenie standardowe: {avg_std:.4f}, Współczynnik korekcyjny: {correction_factor:.4f}")
        return correction_factor

    def convert_model_holistic(self, model, clip, vae, conversion_direction, model_architecture, processing_device, recalculation_steps, calibration_strength, recalculation_strength, simulation_batch_size, optimizer_lr, use_fp16):
        if recalculation_strength == 0.0:
            return (model, clip, vae,)

        print(f"Start: Konwerter Modelu (Holistyczny) - kierunek: {conversion_direction}. To powolny, eksperymentalny proces.")
        
        device = comfy.model_management.get_torch_device() if processing_device.lower() == "gpu" else torch.device("cpu")
        if processing_device.lower() == 'auto':
            device = model.load_device
        
        print(f"Używane urządzenie do obliczeń: {device}")

        model_copy = model.clone()
        original_sd = model.model.state_dict()
        recalculated_sd = copy.deepcopy(original_sd)
        dtype = torch.float16 if use_fp16 and device != torch.device('cpu') else torch.float32
        
        unet = model_copy.model.diffusion_model.to(device)

        arch_details = self._detect_model_arch(unet) if model_architecture == 'auto' else \
                       ({'type': 'sd15', 'context_dim': 768, 'num_classes': None} if model_architecture == 'sd15' else \
                        {'type': 'sdxl', 'context_dim': 2048, 'num_classes': 2816})
        
        if model_architecture != 'auto':
            print(f"--> Ręczne nadpisanie architektury: {arch_details['type'].upper()}")

        final_correction_factor = 1.0
        if conversion_direction == "epsilon_to_v":
            base_correction_factor = self.calibrate_model(model, unet, 15, device, dtype, arch_details)
            final_correction_factor = 1.0 + (base_correction_factor - 1.0) * calibration_strength
            if final_correction_factor != 1.0:
                print(f"Aplikowanie finalnego współczynnika korekcyjnego: {final_correction_factor:.4f}")
        else:
            print("Pomijanie kalibracji dla konwersji v -> epsilon.")

        try:
            sigmas = model.model.model_sampling.sigmas.to(device, dtype=dtype)
            mid = len(sigmas) // 2
            selected_sigmas = sigmas[max(0, mid - recalculation_steps // 2) : min(len(sigmas), mid + (recalculation_steps + 1) // 2)]
        except (AttributeError, TypeError):
            print("--> Ostrzeżenie: Nie można pobrać harmonogramu sigma. Używam sigm w przestrzeni logarytmicznej.")
            selected_sigmas = torch.logspace(torch.log10(torch.tensor(0.1)), torch.log10(torch.tensor(10.0)), steps=recalculation_steps).to(device, dtype=dtype)

        print(f"Rekalkulacja będzie przeprowadzona dla {len(selected_sigmas)} wartości sigma.")

        module_list = [m for m in unet.modules() if isinstance(m, (torch.nn.Conv2d, torch.nn.Linear))]
        pbar = comfy.utils.ProgressBar(len(module_list))
        
        for i, (name, module) in enumerate(unet.named_modules()):
            if not isinstance(module, (torch.nn.Conv2d, torch.nn.Linear)):
                continue

            weight_key, bias_key = f"{name}.weight", f"{name}.bias"
            if weight_key not in original_sd: continue
            
            print(f"\nPrzetwarzanie modułu {i+1}/{len(module_list)}: {name} ({'Conv2d' if isinstance(module, torch.nn.Conv2d) else 'Linear'})")

            original_weight = original_sd[weight_key].to(device, dtype=dtype)
            accumulated_recalculated_weight = torch.zeros_like(original_weight)
            
            for sigma in selected_sigmas:
                comfy.model_management.throw_exception_if_processing_interrupted()
                
                is_conv = isinstance(module, torch.nn.Conv2d)
                in_shape = (simulation_batch_size, module.in_channels, 32, 32) if is_conv else (simulation_batch_size, module.in_features)
                dummy_input = torch.randn(in_shape, device=device, dtype=dtype)
                
                module.weight.data.copy_(original_weight)
                if module.bias is not None and bias_key in original_sd:
                    module.bias.data.copy_(original_sd[bias_key].to(device, dtype=dtype))
                
                with torch.no_grad():
                    original_pred_output = module(dummy_input)
                    if conversion_direction == "epsilon_to_v":
                        original_pred_output *= final_correction_factor

                target_output = self.get_target_v_pred(original_pred_output, dummy_input, sigma) if conversion_direction == "epsilon_to_v" else \
                                self.get_target_epsilon_pred(original_pred_output, dummy_input, sigma)
                
                if is_conv:
                    temp_module = copy.deepcopy(module).to(device, dtype=dtype)
                    temp_module.weight.requires_grad_(True)
                    if temp_module.bias is not None: temp_module.bias.requires_grad_(False)
                    
                    optimizer = torch.optim.Adam([temp_module.weight], lr=optimizer_lr)
                    loss_fn = torch.nn.MSELoss()
                    
                    for _ in range(3):
                        optimizer.zero_grad()
                        loss = loss_fn(temp_module(dummy_input), target_output)
                        loss.backward()
                        optimizer.step()
                    
                    recalculated_weight_step = temp_module.weight.detach()
                    del temp_module, optimizer, loss_fn, loss
                else:
                    X = dummy_input.view(simulation_batch_size, -1)
                    Y_target = target_output.view(simulation_batch_size, -1)
                    if module.bias is not None: Y_target -= original_sd[bias_key].to(device, dtype=dtype)
                    try:
                        W_T = torch.linalg.lstsq(X, Y_target).solution
                        recalculated_weight_step = W_T
                    except torch.linalg.LinAlgError:
                        recalculated_weight_step = original_weight

                accumulated_recalculated_weight += recalculated_weight_step
                del dummy_input, original_pred_output, target_output, recalculated_weight_step
            
            averaged_recalculated_weight = accumulated_recalculated_weight / len(selected_sigmas)
            final_weight = torch.lerp(original_weight, averaged_recalculated_weight, recalculation_strength)
            recalculated_sd[weight_key] = final_weight.to('cpu', copy=True)
            
            del original_weight, accumulated_recalculated_weight, averaged_recalculated_weight, final_weight
            if device != torch.device('cpu'):
                torch.cuda.empty_cache()
            gc.collect()
            
            pbar.update(1)

        print("\n--> Rekalkulacja StateDict zakończona.")
        unet.to(torch.device("cpu"))
        model_copy.model.load_state_dict(recalculated_sd)
        
        target_prediction_type = "v_prediction" if conversion_direction == "epsilon_to_v" else "epsilon"
        print(f"--> Ustawianie typu predykcji modelu na: {target_prediction_type}")
        model_copy.model_options.setdefault('model_config', {}).set_prediction_type(target_prediction_type)


        del unet, original_sd, recalculated_sd
        if device != torch.device('cpu'):
            torch.cuda.empty_cache()
        gc.collect()

        return (model_copy, clip, vae,)

Krok 1: Stworzenie i konwersja bazy 'Nowa Hybryda'

Najpierw, używając oryginalnego przewodnika, stwórz finalny model metodą "Hybrydowego Łatania". Następnie, podłącz go (wraz z jego CLIP i VAE) do nowego węzła `AdvancedModelConverter`. Użyj poniższych ustawień jako punktu wyjścia:

  • conversion_direction: `epsilon_to_v`
  • processing_device: `GPU` (lub `CPU` jeśli VRAM jest problemem)
  • recalculation_steps: `12` (dobry kompromis między jakością a czasem)
  • calibration_strength: `1.0`
  • recalculation_strength: `1.0` (dla pełnej konwersji)

Wynikiem będzie Twój model bazowy, teraz w formacie V-Prediction, gotowy do dalszego łączenia. Zapisz go jako `NewHybrid_vpred.safetensors`.

Krok 3: Chirurgiczne Łączenie CLIP (DARE-TIES)

Proste połączenie lub wybór jednego z enkoderów CLIP jest niewystarczające. Twój `NewHybrid` CLIP jest "trójjęzyczny" (Pony + SDXL + Język naturalny), a CLIP `New Era` jest wysoko wyspecjalizowany. Naiwne połączenie doprowadziłoby do konfliktu i utraty zdolności rozumienia promptów. Dlatego zastosujemy precyzyjną, chirurgiczną metodę DARE-TIES.

Cel: Przeszczepienie "rozumienia stylu" z CLIP New Era do Twojego bazowego CLIP, przy minimalnym naruszeniu jego złożonej struktury.

1. Zdefiniuj Role i Wymagania:

  • CLIP A (Host): CLIP z Twojego `NewHybrid_vpred.safetensors`. To jest baza, którą chcemy wzbogacić.
  • CLIP B (Donor): CLIP z `New Era 6.3`. Dawca stylu.
  • Base Model CLIP (Kluczowe!): CLIP z oryginalnego `sd_xl_base_1.0.safetensors`. Jest niezbędny do obliczenia "wektorów zadań" (delta-parametrów), na których operuje DARE-TIES.

2. Użyj węzła `CLIP Merger (DARE)`:

Ten węzeł znajdziesz w pakiecie `ComfyUI-DareMerge`.

3. Zalecane Parametry:

  • clip_a: Podłącz CLIP z `NewHybrid_vpred`.
  • clip_b: Podłącz CLIP z `New Era 6.3`.
  • base_model: Podłącz CLIP z `sd_xl_base_1.0`.
  • ratio: 0.65 - Stosunkowo wysoka wartość, aby dać stylowi New Era znaczący wpływ.
  • drop_rate: 0.75 - Agresywne przerzedzanie. Zachowujemy tylko 25% najważniejszych "instrukcji stylistycznych" z New Era, minimalizując ryzyko konfliktu.
  • ties: on (lub `sum`) - Absolutnie kluczowe. Rozwiązuje konflikty, gdy oba CLIPy chcą modyfikować ten sam parametr w przeciwnych kierunkach.
  • rescale: on - Niezbędne, aby wzmocnić sygnał z 25% zachowanych parametrów.
  • seed: Zacznij od stałej wartości (np. 12345), a następnie eksperymentuj z innymi, aby znaleźć najlepszy rezultat.

Krok 4: Finalizacja i Zapis Modelu

Ostateczny Montaż

Po przygotowaniu obu kluczowych komponentów, czas na ich ostateczne połączenie. Użyj węzła `CheckpointSave`.

  • MODEL (UNet): Podłącz wyjście z węzła `ModelMergeBlocks` z Kroku 2.
  • CLIP: Podłącz wyjście z węzła `CLIP Merger (DARE)` z Kroku 3.
  • VAE: Zdecydowanie użyj VAE z Twojego oryginalnego modelu `NewHybrid_vpred.safetensors`. Ponieważ baza UNet jest wciąż Twoją konstrukcją, jej VAE zapewni najlepszą wierność kolorów.

Nadaj swojemu nowemu dziełu nazwę, np. `DarkHybridEra_v1.safetensors` i zapisz. Jesteś gotowy do generowania! Pamiętaj, że stworzyłeś zupełnie nowy model – kluczem do pełnego wykorzystania jego potencjału jest teraz nowa faza eksperymentów z promptami, aby odkryć, jak najlepiej komunikować się z jego unikalną, połączoną "świadomością".
